AMP Uploader: Privacy policy

Last updated: 2026-10-21

Who uses it

AMP Uploader is used only by its owner, a math teacher, to upload his own videos to his own YouTube channel. It is not offered to the public.

What it accesses

With the owner's permission (Google OAuth), the program uses the YouTube Data API to upload videos, set their titles, descriptions and privacy status, and read the name of the owner's own channel. It does not read, collect or process any other person's data.

What it stores

The OAuth sign-in token is stored only on the owner's own computer. No data is sent to any server other than Google's YouTube API, and nothing is sold, shared or used for advertising.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

AMP Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Through the YouTube channel that uses this tool.
